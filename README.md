# SentinelKey

🛡️ **Secret Scanner for GitHub Repositories**

SentinelKey detects exposed credentials, API keys, and secrets in GitHub repositories using [Gitleaks](https://github.com/gitleaks/gitleaks).

## Features

- **Web Dashboard**: Streamlit-based UI for on-demand scanning
- **CI/CD Integration**: Automatic scanning on push/PR via GitHub Actions
- **Discord Alerts**: Real-time notifications when secrets are found
- **Database Storage**: Scan history stored in Supabase

## Quick Start

### 1. Deploy Dashboard
[![Deploy to Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/)

### 2. Configure Secrets

**Streamlit Cloud:**
```toml
SUPABASE_URL = "https://your-project.supabase.co"
SUPABASE_KEY = "your-anon-key"
GITHUB_PAT = "ghp_your-token"
GITHUB_OWNER = "YourUsername"
GITHUB_REPO = "sentinelkey"
```

**GitHub Actions:**
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `DISCORD_WEBHOOK_URL` (optional)

### 3. Create Supabase Table
```sql
create table scan_history (
  id bigint generated by default as identity primary key,
  timestamp timestamptz default now(),
  repo text,
  results jsonb,
  status text default 'clean'
);
```

## Usage

1. Open dashboard
2. Enter repository URL
3. Click **Analyze**
4. View results

## Architecture

```
User → Streamlit Dashboard → GitHub Actions → Gitleaks → Supabase → Dashboard
                                    ↓
                              Discord Alert
```
